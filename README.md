# TFP_weather

China county-level agricultural TFP × weather — replication of the Chambers–Pieralli
AJAE production-frontier approach (DEA / SFA with weakly-disposable weather).

Data (`data/`, `src/clean/`, `src/figures/`) is **gitignored** — it is regenerated by
running the pipeline below. Only code, docs, and hand-curated inputs
(`data/manual_impute_list.csv`) are tracked.

## Pipeline (run in order)

**1. Build & clean the county I-O panel**
- `src/00_build_base_panel.do` — merge GVP + labour + agg accounts → `data/base_panel.dta`
- `src/00d_resolve_roster.py` → `src/00e_apply_resolution.py` — county id/name correction
  against the authoritative ag-county list → `data/io_raw_corrected.dta`
- `src/01_clean_panel.py` — value cleaning (÷10000 fixes, 0/<1→NA, boundary trims,
  cross-county placeholders, spike-and-revert imputation, deflation) → `src/clean/county_panel_clean.csv`
- `src/01b_manual_impute.py` — manual multi-year imputation from `data/manual_impute_list.csv`
- `src/02_county_review.py` — per-county review SVGs
- Cleaning logic documented in `县级农业数据清洗.md`.

**2. TFP estimation**
- `src/09_dea_vs_fe_tfp.py` — DEA sequential-NIRS Malmquist + FE Solow (per-county output)
- `src/11_sfa_bc92_tfp.do` — land-normalized SFA (pooled frontier; wrong-skewness → σ_u≈0)
- `src/16_sfa_bc92_tnormal.do` / `src/17_sfa_sub1000.do` — BC92 tnormal (full stalls;
  converges on a 1000-county subsample)

**3. Aggregation & analysis**
- `src/12_aggregate_compare.py` — national TFP: simple vs output-share (Törnqvist) weighting
- `src/13`–`15`, `18`, `19` — volatility diagnostics, by-year volatility, winsorized/stage
  analysis (five reform stages), subsample comparison, literature benchmark

**4. Production-frontier figures**
- `src/23_io_combined.py` — per-year 3-D Cobb-Douglas surface + its three 2-D projections

Superseded scripts are kept in `src/_archive/`.

## Environment
Python (pandas, numpy, scipy, statsmodels, matplotlib, linearmodels);
Stata 19 MP (`sfpanel`); R (`frontier`, `plm`).
