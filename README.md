# TFP_weather

China county-level agricultural TFP × weather, 1981–2016 — replication of the
Chambers–Pieralli AJAE production-frontier approach (DEA / SFA with weakly-disposable
weather).

Method, data-cleaning rules and weather-variable construction are documented in
**[METHODOLOGY.md](METHODOLOGY.md)**. This file is the pipeline map.

Data (`data/`, `src/clean/`, `src/figures/`, `src/dq/`) is **gitignored** — it is
regenerated by running the pipeline below. Only code, docs and hand-curated inputs
(`data/manual_impute_list.csv`, the `data/ag_county/` lists) are tracked.

## Layout

`src/` is flat and the numeric prefix *is* the pipeline order. Modules shared across
stages are prefixed with `_` and carry no number.

| block | stage |
|---|---|
| `00` | cropland shares → the agricultural-county definition |
| `00`–`04` | build & clean the county input–output panel |
| `10`–`14` | weather variables (GDD/HDD, growing season, soil moisture) |
| `20`–`24` | frontier estimation (DEA, SFA, descriptives, framework tables) |
| `30`–`31` | national aggregation & volatility diagnostics |
| `40`–`41` | CPS (2020) four-component decomposition |
| `50`–`56` | figures |
| `59`–`61` | sample audits and the screening dashboards |

Shared modules: `_common.py` (paths, the five I-O variables, county-type labels, CJK
font, imputation primitives) · `_frontier.py` (**every** frontier estimator — DEA hull,
order-α quantile boundary, LP isoquant, the input index, 九大农业区) · `_tfp.py` (input
elasticities read live from the SFA output, winsorizing, Solow residual, reform stages) ·
`_county_match.py` (layered county↔boundary matcher) · `_county_corrections.py`
(hand-curated renames/merges/removals) · `_degree_days.py` (single-sine degree days) ·
`_multipeak_season.py` (circular peak detection).

## Pipeline

### 1. Build & clean the county I-O panel
```bash
python src/00_cropland_share.py       # CACD 30m cropland share per county PER YEAR
python src/00_build_base_panel.py     # GVP + labour + agg accounts -> data/base_panel.dta
python src/01_resolve_roster.py       # county id/name resolution against the ag-county list
python src/02_apply_resolution.py     # apply it -> data/io_raw_corrected.dta
python src/03_clean_panel.py          # value cleaning + auto and manual imputation
python src/04_county_review.py        # per-county review SVGs (for the manual pass)
```
`00_cropland_share.py` and `00_build_base_panel.py` are independent roots — both feed
`01`. The agricultural-county definition is **cropland ≥ 15% in EVERY raster year
(1986–2015)** → `data/ag_county/ag_counties_strict_aglist.csv`, **1,718 counties**. Two
weaker rules were used before and are kept for comparison:

| rule | counties | why not |
|---|---|---|
| 2010 alone (`ag_counties_crop15.csv`) | ~1,800 | classifies a 36-year panel on one cross-section, and 2010 is the lowest-cropland year of the series |
| ANY year — union (`ag_counties_union_aglist.csv`) | 1,975 | no guard against a brief crossing: 29 counties cleared 15% in only 1–5 of the 30 years yet were carried for all 36 |
| **EVERY year — strict (current)** | **1,718** | — |

Known limit: the strict rule removes 294 counties but **does not** fix the peri-urban
problem it was expected to — the urban-district share of the sample moves only
31.2% → 30.6%, because those districts genuinely hold ≥15% cropland every year.
Separating them needs the type indicators in `61_screening_dashboard.py`, not a cropland
threshold.

The panel keeps **all resolved rural counties** (2,477) and carries `ag_county` as a 0/1
flag rather than filtering — so the cleaned panel is reusable, and the agricultural
restriction is `T.load_panel()` (default), `T.load_panel(ag_only=False)`, or
`keep if ag_county == 1` in Stata.

`03` is one pass: ÷10,000 unit fixes → deflation → caliber-year detection →
spike-and-revert imputation → the manual multi-year stretches listed in
`data/manual_impute_list.csv`. Every change is reversible (`<var>_raw`, `<var>_imp`).
`--no-manual` stops after the automatic step. Rules: METHODOLOGY.md §9.

The manual list is built by eye from `04`'s figures, so the intended loop is
`03 → 04 → edit the list → 03`.

### 2. Weather variables
```bash
python src/10_monthly_gdd_hdd.py --year-range 1982-2016   # the one expensive raster pass
python src/10_monthly_gdd_hdd.py --extend 1981            # merge the missing year in
python src/11_growing_season.py                           # cropland-NDVI multi-peak season mask
python src/12_county_gdd_hdd.py                           # -> county-year GDD/HDD + io_weather_panel.csv
python src/13_county_soil_moisture.py                     # -> county-year root-zone soil moisture
python src/14_annual_gdd_cropshare.py                     # whole-year variant + cropland share
```
`10` writes a **monthly** archive, so every later season definition is an array
multiply rather than another pass over 25,550 daily rasters. Requires the raster
archive on `Z:/weather data/`. Construction and thresholds: METHODOLOGY.md §10.

### 3. Frontier estimation
```bash
python src/20_dea_tfp.py                        # DEA sequential-NIRS Malmquist
python src/20_dea_tfp.py --exclude-counties src/dq/exclude_16.csv --tag _excl16
do     src/21_sfa_bc92.do                       # BC92 SFA, Cobb-Douglas, NIRS
do     src/22_descriptives.do                   # moments, panel structure, stage tables
python src/24_io_index_descriptives.py          # I-O + index descriptives, plotted ranges
do     src/23_dea_sfa_framework.do              # Malmquist decomposition, DEA×SFA
```
`20` takes `--from-year` (default 1985), `--exclude-counties` and `--tag`. `21` imposes
**NIRS by the KKT argument** rather than CRS by land-normalisation (METHODOLOGY §4) and
exports the frontier coefficients that `_tfp.BETA_AG` now reads **live** from
`src/clean/sfa_surface_coefs.csv`, so a re-estimation propagates to every figure without
anyone editing a literal.

Both start at **1985**: `capital_serv_q` behaves differently before it (median K/M runs
0.008–0.012 over 1981–84 against 0.0023–0.0039 after) and county coverage nearly doubles
at 1985 (1,082 → 1,819), so the early block is a different series on a different sample.

### 4. Aggregation & diagnostics
```bash
python src/30_aggregate_tfp.py    # national annual series: simple vs Törnqvist, raw vs
                                  # winsorized, five reform stages, 1,000-county comparison
python src/31_volatility.py       # is the ±20% annual swing an artifact? where does it come
                                  # from? by-year volatility; against the literature band
```

### 5. CPS weather decomposition
```bash
python src/40_cps_prep.py           # scalar Törnqvist input index + (y, x, w) frame
python src/41_cps_decomposition.py  # ln TFP = dT + dW + dX + dE, weak disposability in w
```

### 6. Figures
```bash
python src/50_io_surface.py             # per-year 3-D Cobb-Douglas surface + 2-D projections
python src/51_dea_decomposition_fig.py  # TFP = technical change × efficiency change
python src/52_frontier_figs.py          # ALL frontier/isoquant figures, one engine
python src/52_frontier_figs.py --by-region   # ... faceted by 九大农业区
python src/54_weather_descriptive.py    # weather × outcome scatter by period
python src/55_spike_choropleth_tfp.py   # TFP choropleth with GVP spikes
python src/56_weather_figs.py           # weather overview + input-weather frontier + f(x,w) surface
```
`52` replaced `52_frontier_isoquant_figs.py`, `53_frontier_isoquant_expansion.py` and
`58_aggregate_frontier.py`, which had drifted into three different constructions of the
same boundary. `56` replaced `56_weather_overview.py` and `57_weather_frontier.py`.
All axes are **linear**: a level-space concave hull draws as an upward-bowing arc on
log-log, because the plot then shows the elasticity, not the marginal product.

### 7. Sample audits and screening
```bash
python src/59_frontier_audit.py     # who defines each frontier, and how far it moves without them
python src/60_leave_one_out.py      # drop the vertex counties, re-solve, measure the shift
python src/61_screening_dashboard.py  # three self-contained HTML maps, 1981-2016
```
These exist because the boundary is set by a handful of counties: dropping 16 of them
moves mean DEA efficiency **+22%** and mean SFA efficiency **+91%**, while TFP *growth*
moves only 4.24 → 4.15 %/yr. Levels are fragile, growth is not — and the EFFCH/TECHCH
split is fragile too (−39% and −13%), so it should not be quoted on its own.

rasterio, xarray, exactextract); Stata 19 MP (`sfpanel`, `winsor2`).
