# TFP_weather

China county-level agricultural TFP × weather, 1981–2016 — replication of the
Chambers–Pieralli AJAE production-frontier approach (DEA / SFA with weakly-disposable
weather).

Method, data-cleaning rules and weather-variable construction are documented in
**[METHODOLOGY.md](METHODOLOGY.md)**. This file is the pipeline map.

Data (`data/`, `src/clean/`, `src/figures/`) is **gitignored** — it is regenerated by
running the pipeline below. Only code, docs and hand-curated inputs
(`data/manual_impute_list.csv`, `data/ag_county/ag_counties_crop15.csv`) are tracked.

## Layout

`src/` is flat and the numeric prefix *is* the pipeline order. Modules shared across
stages are prefixed with `_` and carry no number.

| block | stage |
|---|---|
| `00` | cropland shares → the agricultural-county definition |
| `00`–`04` | build & clean the county input–output panel |
| `10`–`14` | weather variables (GDD/HDD, growing season, soil moisture) |
| `20`–`23` | frontier estimation (DEA, SFA, descriptives, framework tables) |
| `30`–`31` | national aggregation & volatility diagnostics |
| `40`–`41` | CPS (2020) four-component decomposition |
| `50`–`55` | figures |

Shared modules: `_common.py` (paths, the five I-O variables, geography filter, CJK
font, imputation primitives) · `_tfp.py` (Törnqvist aggregation, winsorizing, Solow
residual, reform stages and period cuts) · `_county_match.py` (layered county↔boundary
matcher) · `_county_corrections.py` (hand-curated renames/merges/removals) ·
`_degree_days.py` (single-sine degree days) · `_multipeak_season.py` (circular
peak detection).

## Pipeline

### 1. Build & clean the county I-O panel
```bash
python src/00_cropland_share.py       # CACD 30m cropland share per county PER YEAR
python src/00_build_base_panel.py     # GVP + labour + agg accounts -> data/base_panel.dta
python src/01_resolve_roster.py       # county id/name resolution against the ag-county list
python src/02_apply_resolution.py     # apply it -> data/io_raw_corrected.dta
python src/03_clean_panel.py          # value cleaning + auto and manual imputation
python src/04_county_review.py        # per-county review SVGs (for the manual pass)
```
`00_cropland_share.py` and `00_build_base_panel.py` are independent roots — both feed
`01`. The agricultural-county definition is **cropland ≥ 15% in ANY year (1986–2015)**,
not in 2010 alone: a single-year snapshot classifies a 1981–2016 panel on one
cross-section and drops counties that urbanised mid-sample, which conditions the sample
on the very transition being studied. Per-year shares are all written out, so an
intersection or k-of-n rule can be built without re-reading a raster. Runtime ~4 min/year
at full 30 m resolution; the run is resumable.

The panel keeps **all ~2,500 resolved rural counties** and carries `ag_county` as a 0/1
flag rather than filtering — so the cleaned panel is reusable, and the agricultural
restriction is `T.load_panel()` (default), `T.load_panel(ag_only=False)`, or
`keep if ag_county == 1` in Stata.

`03` is one pass: ÷10,000 unit fixes → deflation → caliber-year detection →
spike-and-revert imputation → the manual multi-year stretches listed in
`data/manual_impute_list.csv`. Every change is reversible (`<var>_raw`, `<var>_imp`).
`--no-manual` stops after the automatic step. Rules: METHODOLOGY.md §9.

The manual list is built by eye from `04`'s figures, so the intended loop is
`03 → 04 → edit the list → 03`.

### 2. Weather variables
```bash
python src/10_monthly_gdd_hdd.py --year-range 1982-2016   # the one expensive raster pass
python src/10_monthly_gdd_hdd.py --extend 1981            # merge the missing year in
python src/11_growing_season.py                           # cropland-NDVI multi-peak season mask
python src/12_county_gdd_hdd.py                           # -> county-year GDD/HDD + io_weather_panel.csv
python src/13_county_soil_moisture.py                     # -> county-year root-zone soil moisture
python src/14_annual_gdd_cropshare.py                     # whole-year variant + cropland share
```
`10` writes a **monthly** archive, so every later season definition is an array
multiply rather than another pass over 25,550 daily rasters. Requires the raster
archive on `Z:/weather data/`. Construction and thresholds: METHODOLOGY.md §10.

### 3. Frontier estimation
```bash
python src/20_dea_vs_fe_tfp.py                  # DEA sequential-NIRS Malmquist + FE Solow
do     src/21_sfa_bc92.do full    tnormal       # BC92 SFA on all ~1,830 ag counties
do     src/21_sfa_bc92.do sub1000 tnormal       # 1,000-county robustness check
do     src/22_descriptives.do                   # moments, panel structure, stage tables
do     src/23_dea_sfa_framework.do              # Malmquist decomposition, convergence, DEA×SFA
```
`21` takes `SAMPLE DIST [FULLTRY]`; it also exports the frontier coefficients the
3-D surface figure needs. **It converges on the full agricultural sample** (N=58,914,
1,832 counties, 17 iterations, ~42 min, γ=0.693) — the 1,000-county subsample is now a
robustness check, not a necessity. Elasticities live in `_tfp.BETA_AG`.

### 4. Aggregation & diagnostics
```bash
python src/30_aggregate_tfp.py    # national annual series: simple vs Törnqvist, raw vs
                                  # winsorized, five reform stages, 1,000-county comparison
python src/31_volatility.py       # is the ±20% annual swing an artifact? where does it come
                                  # from? by-year volatility; against the literature band
```

### 5. CPS weather decomposition
```bash
python src/40_cps_prep.py           # scalar Törnqvist input index + (y, x, w) frame
python src/41_cps_decomposition.py  # ln TFP = dT + dW + dX + dE, weak disposability in w
```

### 6. Figures
```bash
python src/50_io_surface.py             # per-year 3-D Cobb-Douglas surface + 2-D projections
python src/51_dea_decomposition_fig.py  # TFP = technical change × efficiency change
python src/52_frontier_isoquant_figs.py # single-year frontiers & unit isoquants (OECD Fig 9/10)
python src/53_frontier_isoquant_expansion.py  # Fig 9 frontier, Fig 10 isoquant,
                                              # Fig 11 input expansion path (by YEAR)
python src/54_weather_descriptive.py    # weather × outcome scatter by period
python src/55_spike_choropleth_tfp.py   # TFP choropleth with GVP spikes
```

## Environment
Python (pandas, numpy, scipy, statsmodels, matplotlib, linearmodels, geopandas,
